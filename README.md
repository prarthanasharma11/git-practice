# Commands Used
<br>
git init : It is used to initialize a new Git repository in a project folder. <br>
git add . : It adds all modified and new files in the current directory to the staging area. <br>
git commit -m : saves the staged changes to the local repository history.<br>
git remote -v : Shows the remote repositories linked to your local repository.<br>
git remote add origin <url> : This command connects your local repository to a remote repository.<br>
git branch : Shows the list of branches in the repository.<br>
git checkout : It is used to switch between branches or restore files.<br>
git diff : Shows the difference between file versions.<br>
git merge : It is used to combine changes from one branch into another.<br>
git push origin main : Uploads the local commits to the remote repository on GitHub.<br>
